Python & Data Science Fundamentals
Overview

This repository contains my hands-on practice in Python fundamentals for Data Science as part of my internship learning journey.

The notebooks focus on building a strong foundation in Python through practical examples and exercises, covering variables, conditional statements, loops, functions, and file handling.

The work is implemented using Google Colab / Jupyter Notebook and is designed to strengthen Python programming skills required for Data Science and analytics.

Objectives

Build a strong foundation in Python programming.
Understand and work with different Python data types.
Practice conditional statements and decision-making.
Understand and implement different types of loops.
Create and use Python functions.
Perform basic file operations using Python.
Develop practical programming skills applicable to Data Science.

Integer, Float, String, and Boolean data types
Arithmetic operators
Conditional statements

Basic string operations
String indexing
upper() and lower()

Topics practiced:

The third notebook introduces reusable blocks of code using Python functions.
